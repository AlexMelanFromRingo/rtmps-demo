# Кодекс поведения

Участники StreamHub (в issues, pull request, обсуждениях и любых других каналах проекта)
следуют **[Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)**.
Есть [официальный перевод на русский](https://www.contributor-covenant.org/ru/version/2/1/code_of_conduct/).
При расхождениях действует английская версия.

Коротко: уважайте собеседников, критикуйте код, а не людей, и помните, что у проекта
участники с разным опытом, из разных стран, пишущие на разных языках. Недопустимы домогательства,
оскорбления, публикация чужих личных данных и сексуализированный контент. Не разрешено
и другое поведение, которое в профессиональной среде сочли бы неуместным.

## Как сообщить о нарушении

Напишите мейнтейнеру проекта (GitHub: [AlexMelanFromRingo](https://github.com/AlexMelanFromRingo))
приватно. Если не знаете, как связаться приватно, откройте issue с просьбой выйти на связь,
но без подробностей инцидента. Каждое обращение рассматривается конфиденциально. Меры
(от предупреждения до бана) принимаются по разделу «Enforcement Guidelines» Contributor Covenant 2.1.

Об уязвимостях сообщайте не сюда, а по процедуре из [SECURITY.md](SECURITY.md).
