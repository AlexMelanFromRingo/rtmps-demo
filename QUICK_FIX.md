# 🚨 БЫСТРОЕ ИСПРАВЛЕНИЕ: Смена кодека в OBS

## ❌ У вас сейчас: AV1 → ✅ Нужно: H.264

---

## 📋 ПОШАГОВАЯ ИНСТРУКЦИЯ (5 минут)

### Шаг 1: Откройте настройки OBS
**Файл → Настройки** (или Settings)

### Шаг 2: Перейдите в "Вывод" (Output)
В левой панели нажмите на **"Вывод"** или **"Output"**

### Шаг 3: Переключите режим на "Расширенный"
```
┌─────────────────────────────────────┐
│ Режим вывода: [Простой      ▼]  ❌ │ ← Сейчас
└─────────────────────────────────────┘

         ⬇️  ИЗМЕНИТЕ НА  ⬇️

┌─────────────────────────────────────┐
│ Режим вывода: [Расширенный  ▼]  ✅ │ ← Правильно
└─────────────────────────────────────┘
```

### Шаг 4: Найдите "Кодировщик видео"

В разделе **"Трансляция"** (Streaming) найдите поле **"Кодировщик видео"** (Video Encoder)

**Сейчас у вас:**
```
┌──────────────────────────────────────────┐
│ Кодировщик видео:                        │
│ [AV1 NVENC                        ▼] ❌ │ ← НЕПРАВИЛЬНО!
└──────────────────────────────────────────┘
```

### Шаг 5: Измените на H.264

**Нажмите на выпадающий список и выберите:**
```
┌──────────────────────────────────────────┐
│ Кодировщик видео:                        │
│ [NVIDIA NVENC H.264 (new)         ▼] ✅ │ ← ПРАВИЛЬНО!
└──────────────────────────────────────────┘
```

**Альтернативы:**
- ✅ `NVIDIA NVENC H.264`
- ✅ `x264` (если нет NVENC)

**НЕ выбирайте:**
- ❌ `AV1 NVENC`
- ❌ `SVT-AV1`
- ❌ `HEVC NVENC`
- ❌ `AMD AV1`

### Шаг 6: Настройте битрейт

После выбора H.264, настройте:
```
Управление битрейтом: [CBR           ▼]
Битрейт: [6000] Kbps
Интервал ключевых кадров: [2]
Предустановка: [Quality          ▼]
```

### Шаг 7: Примените изменения
1. Нажмите **"Применить"** внизу
2. Нажмите **"OK"**

### Шаг 8: Перезапустите OBS
**ВАЖНО:** Закройте OBS и откройте заново!

### Шаг 9: Начните трансляцию
Теперь можно начать трансляцию - видео должно работать! ✅

## ✅ ПРОВЕРКА: Все правильно?

После изменений проверьте:

### 1. В настройках OBS:
```
✅ Режим: Расширенный
✅ Кодировщик: NVIDIA NVENC H.264 (или x264)
✅ Битрейт: 6000 Kbps
```

### 2. Начните трансляцию

### 3. Проверьте логи сервера (в WSL):
Должно быть:
```
✅ [FFmpeg] Starting transcoding...
✅ Stream #0:1: Video: h264, yuv420p, 1920x1080, 60 fps
```

**НЕ должно быть:**
```
❌ Video codec (d) is not implemented
❌ Video: none ([13][0][0][0] / 0x000D)
```

---

## 🆘 Если H.264 нет в списке

### Вариант 1: Обновите драйверы NVIDIA
1. Откройте **GeForce Experience**
2. **Драйверы → Проверить обновления**
3. Установите последние драйверы
4. Перезагрузите компьютер
5. Снова откройте OBS

### Вариант 2: Используйте x264
Если NVENC недоступен, используйте x264:
```
Кодировщик видео: [x264           ▼]
Предустановка CPU: [veryfast      ▼]
Битрейт: 6000 Kbps
```

> **Примечание:** x264 использует CPU вместо GPU
