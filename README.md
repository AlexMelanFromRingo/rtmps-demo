# 📡 RTMP Streaming Server

Простой RTMP сервер для стриминга с веб-интерфейсом - ваш личный мини-Twitch!

## 🎯 Возможности

- ✅ **RTMP сервер** для приема потока от OBS Studio
- ✅ **Генерация ключей трансляции** через веб-интерфейс
- ✅ **HLS конвертация** для просмотра в браузере
- ✅ **Веб-плеер** для просмотра трансляций в реальном времени
- ✅ **Управление трансляциями** - создание, просмотр, удаление ключей
- ✅ **Статусы в реальном времени** - онлайн/оффлайн индикаторы

## 🚀 Быстрый старт

### Требования

- Node.js (версия 14 или выше)
- FFmpeg (для конвертации RTMP → HLS)

### Установка FFmpeg

**Ubuntu/WSL2:**
```bash
sudo apt update
sudo apt install ffmpeg
```

**Windows:**
- Скачайте FFmpeg с официального сайта: https://ffmpeg.org/download.html
- Добавьте путь к FFmpeg в системную переменную PATH

**macOS:**
```bash
brew install ffmpeg
```

### Установка и запуск

1. **Клонируйте репозиторий:**
```bash
git clone <your-repo-url>
cd rtmps-demo
```

2. **Установите зависимости:**
```bash
npm install
```

3. **Запустите сервер:**
```bash
npm start
```

4. **Откройте веб-интерфейс:**
```
http://localhost:3000
```

## 📝 Как использовать

### 1. Генерация ключа трансляции

1. Откройте http://localhost:3000 в браузере
2. Введите название трансляции (опционально)
3. Нажмите "Создать ключ трансляции"
4. Скопируйте **RTMP URL** и **Ключ потока**

### 2. Настройка OBS Studio

1. Откройте **OBS Studio**
2. Перейдите в **Настройки → Трансляция**
3. В поле "Служба" выберите **Пользовательский...**
4. Вставьте данные:
   - **Сервер:** `rtmp://localhost:1935/live`
   - **Ключ потока:** `<ваш сгенерированный ключ>`
5. Нажмите **OK**
6. Нажмите **Начать трансляцию** в главном окне OBS

### 3. Просмотр трансляции

1. На главной странице нажмите кнопку "🚀 Открыть" рядом с ключом
2. Или перейдите по ссылке для просмотра
3. Трансляция начнет воспроизводиться автоматически

## 🔧 Технические детали

### Архитектура

```
OBS Studio → RTMP Server (port 1935) → FFmpeg → HLS → Web Browser
                    ↓
            Express Server (port 3000)
                    ↓
            Web Interface + API
```

### Используемые технологии

- **Backend:**
  - Node.js
  - Express - веб-сервер и API
  - node-media-server - RTMP сервер
  - FFmpeg - конвертация RTMP в HLS

- **Frontend:**
  - Vanilla JavaScript
  - Video.js - HTML5 видеоплеер с HLS поддержкой
  - CSS3 с градиентами и анимациями

### Порты

- **3000** - Веб-интерфейс (HTTP)
- **1935** - RTMP сервер
- **8000** - Media сервер (HLS сегменты)

## 📖 API Endpoints

### POST `/api/generate-key`
Создает новый ключ трансляции

**Body:**
```json
{
  "name": "My Stream"
}
```

**Response:**
```json
{
  "streamKey": "uuid",
  "rtmpUrl": "rtmp://localhost:1935/live",
  "fullUrl": "rtmp://localhost:1935/live/uuid",
  "hlsUrl": "http://localhost:8000/live/uuid/index.m3u8",
  "webPlayerUrl": "http://localhost:3000/watch.html?key=uuid"
}
```

### GET `/api/keys`
Получить список всех ключей

### GET `/api/key/:key`
Получить информацию о конкретном ключе

### DELETE `/api/key/:key`
Удалить ключ (только если трансляция не активна)

## 🐛 Устранение неполадок

### Трансляция не запускается в OBS
- Убедитесь, что сервер запущен
- Проверьте правильность RTMP URL и ключа
- Проверьте логи сервера на наличие ошибок

### Видео не воспроизводится в браузере
- Подождите несколько секунд после начала трансляции (FFmpeg создает HLS сегменты)
- Обновите страницу
- Проверьте консоль браузера на ошибки

### FFmpeg не найден
- Убедитесь, что FFmpeg установлен: `ffmpeg -version`
- В WSL2: `which ffmpeg` должен показать `/usr/bin/ffmpeg`
- При необходимости измените путь в `server.js` (config.trans.ffmpeg)

## 📚 Дополнительная информация

### Про RTMP
RTMP (Real-Time Messaging Protocol) - протокол потоковой передачи данных, разработанный Macromedia (теперь Adobe). Работает поверх TCP, стандартный порт - 1935.

### Про HLS
HLS (HTTP Live Streaming) - протокол потоковой передачи от Apple. Разбивает видео на небольшие сегменты (.ts файлы) и создает плейлист (.m3u8), который может воспроизводиться в любом современном браузере.

### Почему RTMP → HLS?
- RTMP не поддерживается современными браузерами (требует Flash)
- HLS работает через HTTP и поддерживается всеми браузерами
- OBS отправляет RTMP (низкая задержка)
- Браузер получает HLS (совместимость)
