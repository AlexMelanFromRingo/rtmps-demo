📝 Инструкция для OBS Studio:

  1. Откройте OBS Studio
  2. Перейдите в Настройки → Трансляция
  3. Выберите Пользовательский... в поле "Служба"
  4. Вставьте RTMP URL в поле "Сервер"
  5. Вставьте Ключ потока в поле "Ключ потока"
  6. Нажмите OK и Начать трансляцию

📋 Список ключей трансляции

Нажмите "Обновить список" для загрузки ключей

ℹ️ Информация о сервере

  • RTMP порт: 1935
  • Web порт: 3000
  • Media порт: 8000
  • Протокол: RTMP → HLS
