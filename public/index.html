📝 Инструкция для SRT в OBS:

  1. Откройте OBS Studio
  2. Перейдите в Настройки → Трансляция
  3. Выберите Пользовательский...
  4. Вставьте SRT URL в поле "Сервер"
  5. Настройки → Вывод:
  6. • Кодировщик: AV1 NVENC или HEVC NVENC ✨
  7. • Битрейт: 6000-10000 Kbps
  8. Нажмите OK и Начать трансляцию
⚠️ Совместимость: Только H.264 кодек

📝 Инструкция для RTMP в OBS:

  1. Откройте OBS Studio
  2. Перейдите в Настройки → Трансляция
  3. Выберите Пользовательский...
  4. Вставьте RTMP URL в поле "Сервер"
  5. Вставьте Ключ потока в поле "Ключ потока"
  6. Настройки → Вывод:
  7. • Кодировщик: NVIDIA NVENC H.264 (обязательно!)
  8. Нажмите OK и Начать трансляцию
