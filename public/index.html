📝 Настройка OBS для SRT:

  1. Настройки → Трансляция → Сервис: Пользовательский...
  2. Вставьте SRT URL в поле "Сервер"
  3. Настройки → Вывод:
  4. • Кодировщик: AV1 NVENC (RTX 40 series) ⚡
  5. • Или: HEVC NVENC (альтернатива)
  6. • Битрейт: 6000-10000 Kbps (для 1440p ultrawide)
  7. Начать трансляцию 🚀
⚠️ CLASSIC: Только H.264 | Стандартная совместимость

📝 Настройка OBS для RTMP:

  1. Настройки → Трансляция → Сервис: Пользовательский...
  2. Вставьте RTMP URL в поле "Сервер"
  3. Вставьте Stream Key в поле "Ключ потока"
  4. Настройки → Вывод:
  5. • Кодировщик: NVIDIA NVENC H.264 (обязательно!)
  6. • НЕ используйте AV1 или HEVC с RTMP!
  7. Начать трансляцию
